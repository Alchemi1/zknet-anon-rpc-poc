# ZKNetwork + Anon-RPC Proof of Concept

Anon-RPC wallets route Ethereum JSON-RPC through the ZKNetwork Katzenpost mixnet via KPS (Key Pinned Streams). No browser extension required.

## Architecture

```
Browser (Anon-RPC demo page)
  │
  │ AnonRpcWorker({ address: "0xZKNWalletShield" })
  │   → sandboxed Web Worker
  │   → kps.dial("HOST_IP:9201:uEi...")
  │
  ├──── KPS stream (WebRTC from browser, QUIC from native) ────┐
  │                                                              │
  walletshield (Go binary)                                       │
  ├── HTTP listener :9200 (curl, legacy)                         │
  ├── KPS listener  :9201 (NEW — kps.Listen from Go lib)        │
  ├── thin client → kpclientd (TCP 64332)                       │
  │                                                              │
  Docker (mixnet core)                                           │
  ├── mix-dirauth-1/2/3  — PKI consensus                        │
  ├── mix-1/2/3          — Sphinx mix nodes                     │
  ├── mix-gateway        — Client entry point                   │
  ├── mix-servicenode    — Exit node (http-proxy Kaetzchen)     │
  └── mix-client         — kpclientd daemon                     │
```

## Step-by-Step Setup

### 1. Build the Mixnet Docker Image

```bash
# Build for native amd64 (30-60 min — compiles Go + RocksDB from source)
docker build \
  --build-arg TARGETARCH=amd64 \
  --build-arg BUILDER_ARCH=amd64 \
  -t zeros/mixnet-node:amd64 \
  -f Dockerfile.mixnet \
  .
```

### 2. Generate Mixnet Configs

```bash
bash scripts/gen-mixnet-configs.sh
```

### 3. Start the Mixnet

```bash
docker compose up -d

# Wait ~60s for PKI consensus
docker logs mix-client -f
# Wait for: "PKI doc available"
```

### 4. Build walletshield with KPS

```bash
cd walletshield
go mod tidy
go build -trimpath -o walletshield-kps .
cd ..
```

### 5. Build the Worker Bundle

```bash
cd zkn-anon-rpc-worker
npm install
npx esbuild zkn-walletshield-worker.js --bundle --minify --outfile=dist/worker.js
cd ..
```

### 6. Start walletshield

```bash
cd walletshield
./walletshield-kps \
  -config ../config/walletshield/config.toml \
  -listen 127.0.0.1:9200 \
  -kps_listen 0.0.0.0:9201 \
  -log_level INFO
```

### 7. Test the HTTP Proxy

```bash
# In another terminal:
curl -X POST http://127.0.0.1:9200/ethereum \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

Expected output (block number varies):
```json
{"jsonrpc":"2.0","result":"0x...","id":1}
```

### 8. Get the KPS Address

```bash
curl http://127.0.0.1:9200/boot | jq .
```

Returns:
```json
{
  "fetchInit": {
    "address": "0xZKNWalletShield",
    "preExisting": {
      "resolve": "http://127.0.0.1:9200/get-worker"
    }
  },
  "kpsAddr": "127.0.0.1:9201:uEiABCDEF..."
}
```

### 9. Deploy Specifier Contract (Optional)

```bash
cd zkn-anon-rpc-worker
PRIVATE_KEY=0x... RPC_URL=https://ethereum-sepolia.publicnode.com ./deploy.sh
```

### 10. Test with Anon-RPC Demo

Open https://privacy-ethereum.github.io/anon-rpc/demo/ and enter:

| Field | Value |
|---|---|
| Bootstrap RPC URL | Any public Ethereum RPC (e.g. `https://ethereum-sepolia.publicnode.com`) |
| Worker RPC URL | `/ethereum-rpc` |
| Specifier contract | `0x...` (from step 9, or skip for direct test) |

## How It Works

### The Spec

Anon-RPC defines:
- **`IWorkerSpecifier`** — on-chain interface: `workerHash()` + `workerResolvers()`
- **`AnonRpcWorker`** — host-side class: `new AnonRpcWorker({ address })` → `worker.fetch()`
- **`AnonRpcWorkerApi`** — worker-side API: `kps.dial()`, `acceptCall()`, `signalReady()`, `storage`, `log`
- **KPS (Key Pinned Streams)** — transport: multiplexed byte streams pinned by certificate hash (no CA, no DNS)

### What walletshield Does

1. Connects to `kpclientd` at `127.0.0.1:64332` via Katzenpost thin client protocol
2. Listens for HTTP requests on `:9200` (existing) and KPS streams on `:9201` (new)
3. For each request: Sphinx-encrypts → sends through mixnet → receives response → returns to caller

### What the Worker Bundle Does

1. Calls `anonRpcWorker.signalReady()` to signal readiness
2. Calls `anonRpcWorker.acceptCall()` in a loop to receive `FetchCall`s
3. For each call: opens KPS stream to walletshield, writes JSON-RPC as raw HTTP, reads response
4. Returns response via `call.respond()`

### The KPS Integration

The KPS Go library (`github.com/privacy-ethereum/kps/libs/go`) is imported directly into walletshield. It provides:

```
kps.Listen(ctx, addr, opts) → KpsListener
  .Accept(ctx) → KpsConn
    .AcceptStream(ctx) → KpsStream (reliable, ordered, byte-oriented)
    .OpenStream(ctx)   → KpsStream
    .SendDatagram() / .ReceiveDatagram()
```

KPS supports two transports on the same port:
- **WebRTC** — from browsers (used by Anon-RPC demo)
- **QUIC** — from native code (used by test scripts)

## File Details

### walletshield/main.go

The key changes from the original walletshield:

- **`-kps_listen` flag** — enables KPS listener
- **`-contract` flag** — specifier contract address for `/boot` endpoint
- **`startKPSListener()`** — starts KPS listener, registers `/boot` and `/get-worker` HTTP handlers
- **`handleKPSConn()`** — accepts KPS streams, reads bytes, sends through mixnet via `sendRequest()`, writes response back
- Same `sendRequest()` function — Sphinx encryption and mixnet routing unchanged

Original source: `~/zknode-autonomi-v1/walletshield-fix/main.go`
KPS library: `https://github.com/privacy-ethereum/kps`

### zkn-anon-rpc-worker/zkn-walletshield-worker.js

Conforms to Anon-RPC SPEC.md v0.1.0:
- Uses `anonRpcWorker` capability API only
- Calls `signalReady()`, `acceptCall()`, `kps.openStream()`
- Ignores unknown call kinds (spec requirement)
- Uses `respond()` exactly once per call

### ZKNWalletShield.sol

Standard `IWorkerSpecifier` implementation. Stores:
- `workerHash` — keccak256 of the compiled worker bundle
- `workerResolvers` — URLs to fetch the bundle (local `/get-worker` + optional IPFS mirror)

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `docker: command not found` | Docker not installed | Install Docker from https://docs.docker.com/engine/install/ |
| `kpclientd: connection refused` | Mixnet not ready | Wait 60s for PKI consensus, check `docker logs mix-client` |
| `KPS listen failed` | Port 9201 in use | Kill existing process: `pkill walletshield-kps` |
| `PKI doc not available` | Dirauths not in consensus | Check `docker logs mix-dirauth-1` for errors |
| `worker bundle not found` | Worker not built | Run `cd zkn-anon-rpc-worker && npx esbuild ...` |
| WebRTC cannot reach KPS port | Browser on different machine | Use `HOST_IP` instead of `127.0.0.1` for KPS address |
